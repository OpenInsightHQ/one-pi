# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, **please do not open a public issue**.

Instead, report it privately using one of these methods:

- [GitHub private vulnerability reporting](https://github.com/OpenInsightHQ/pi-agent/security/advisories/new)
- Email the maintainers (see the repository owner profile for a contact address)

Please include:

- A description of the issue and its potential impact
- Steps to reproduce (proof of concept, logs, etc.)
- Affected versions/commits
- Any suggested fix or mitigation

We will acknowledge receipt within a reasonable timeframe and keep you informed
of progress. Coordinated disclosure is appreciated.

## Scope

This policy covers the code in this repository. Issues in upstream dependencies
should be reported to their respective maintainers.

## Out of Scope

- Vulnerabilities in third-party LLM provider APIs.
- Issues requiring already-privileged access to a running instance.
- Theoretical attacks without a concrete reproduction.
